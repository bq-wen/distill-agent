# Lin Chen

Lin 是一名后端工程师，近两年专注于 RAG 工程与 Agent 工具治理。

# 工作背景

在一家出行科技公司做后端基础设施，负责搜索相关的检索服务，后转入 AI 应用层团队，开始做 RAG 与 Agent 相关系统。喜欢把"数据契约先行、治理内建"作为系统设计原则。

# 开源与分享

维护两个小项目：一个是 RAG 平台的检索组件，一个是语音助手 Skill 编排框架；也在公司内部分享过工具治理的实践。
